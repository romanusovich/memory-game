## English
# memory-game
A memory match game: a player flips over cards and memorizes their positions to find all pairs in the fewest moves possible.

You can play here: https://romanusovich.github.io/memory-game/
or
You can download the entire project and run it locally by opening `index.html`.

## Русский

# memory-game
Игра на запоминание пар: игрок переворачивает карточки и запоминает их расположение, чтобы найти все пары за минимальное количество ходов.

Ты можешь поиграть здесь: https://romanusovich.github.io/memory-game/
или
Ты можешь скачать весь проект и запустить его локально, открыв `index.html`.
